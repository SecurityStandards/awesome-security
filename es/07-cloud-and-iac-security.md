# Seguridad en la Nube (CSPM, CIEM) e Infraestructura como Código

> Auditoría, cumplimiento, detección de malas configuraciones y gestión de postura en entornos multi-nube (AWS, GCP, Azure) y plantillas IaC.

---

### [Prowler](https://github.com/prowler-cloud/prowler) [![Stars](https://img.shields.io/github/stars/prowler-cloud/prowler?style=social)](https://github.com/prowler-cloud/prowler)
- Herramienta de código abierto para auditorías de seguridad y cumplimiento continuo en AWS, Azure, GCP y Kubernetes alineada con CIS Benchmarks.

### [Checkov](https://github.com/bridgecrewio/checkov) [![Stars](https://img.shields.io/github/stars/bridgecrewio/checkov?style=social)](https://github.com/bridgecrewio/checkov)
- Herramienta de análisis estático para Infraestructura como Código (IaC) que analiza Terraform, CloudFormation, Kubernetes, Helm y ARM.

### [ScoutSuite](https://github.com/nccgroup/ScoutSuite) [![Stars](https://img.shields.io/github/stars/nccgroup/ScoutSuite?style=social)](https://github.com/nccgroup/ScoutSuite)
- Herramienta de auditoría multi-cloud que recopila datos de configuración mediante APIs para resaltar áreas de riesgo en informes HTML interactivos.

### [KICS (Keeping Infrastructure as Code Secure)](https://github.com/Checkmarx/kics) [![Stars](https://img.shields.io/github/stars/Checkmarx/kics?style=social)](https://github.com/Checkmarx/kics)
- Linter de código abierto que identifica vulnerabilidades y fallos de cumplimiento en Terraform, Kubernetes, Ansible y Dockerfiles.

### [CloudFox](https://github.com/BishopFox/cloudfox) [![Stars](https://img.shields.io/github/stars/BishopFox/cloudfox?style=social)](https://github.com/BishopFox/cloudfox)
- Herramienta CLI diseñada para ayudar a pentesters e ingenieros de seguridad a descubrir rutas de ataque explotables en AWS y Azure.
