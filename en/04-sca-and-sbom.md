# SCA (Software Composition Analysis) & SBOM

> Tools for detecting known vulnerabilities (CVEs), outdated dependencies, and open-source license compliance while generating Software Bills of Materials (SBOMs).
> Ferramentas para detectar vulnerabilidades conhecidas (CVEs), dependências desatualizadas e licenças de código aberto, além de gerar SBOMs.

---

### [Trivy](https://github.com/aquasecurity/trivy) [![Stars](https://img.shields.io/github/stars/aquasecurity/trivy?style=social)](https://github.com/aquasecurity/trivy)
- Comprehensive and versatile security scanner for container images, file systems, Git repositories, virtual machine images, and Kubernetes.

### [OSV-Scanner](https://github.com/google/osv-scanner) [![Stars](https://img.shields.io/github/stars/google/osv-scanner?style=social)](https://github.com/google/osv-scanner)
- Vulnerability scanner developed by Google that leverages the distributed Open Source Vulnerabilities (OSV) database.

### [Syft](https://github.com/anchore/syft) [![Stars](https://img.shields.io/github/stars/anchore/syft?style=social)](https://github.com/anchore/syft)
- CLI tool and Go library for generating a Software Bill of Materials (SBOM) from container images and filesystems (SPDX, CycloneDX formats).

### [Grype](https://github.com/anchore/grype) [![Stars](https://img.shields.io/github/stars/anchore/grype?style=social)](https://github.com/anchore/grype)
- Fast vulnerability scanner for container images and filesystems, natively designed to work seamlessly with Syft SBOMs.

### [OWASP Dependency-Check](https://github.com/jeremylong/DependencyCheck) [![Stars](https://img.shields.io/github/stars/jeremylong/DependencyCheck?style=social)](https://github.com/jeremylong/DependencyCheck)
- Traditional Software Composition Analysis utility identifying project dependencies and checking for known publicly disclosed CVEs.

### [Retire.js](https://github.com/RetireJS/retire.js) [![Stars](https://img.shields.io/github/stars/RetireJS/retire.js?style=social)](https://github.com/RetireJS/retire.js)
- Scanner detecting the use of vulnerable JavaScript libraries and Node.js modules in web frontends and backend code.
