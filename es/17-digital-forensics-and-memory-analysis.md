# Informática Forense Digital, Análisis de Memoria y Manejo de Incidentes

> Recopilación de artefactos en sistemas activos, extracción de volcados de memoria RAM, generación de líneas de tiempo y análisis forense.

---

### [Volatility 3](https://github.com/volatilityfoundation/volatility3) [![Stars](https://img.shields.io/github/stars/volatilityfoundation/volatility3?style=social)](https://github.com/volatilityfoundation/volatility3)
- El framework de análisis forense de memoria más utilizado del mundo para extraer artefactos digitales de muestras de memoria RAM.

### [Autopsy](https://github.com/sleuthkit/autopsy) [![Stars](https://img.shields.io/github/stars/sleuthkit/autopsy?style=social)](https://github.com/sleuthkit/autopsy)
- Plataforma libre de informática forense digital e interfaz gráfica para The Sleuth Kit utilizada por peritos y equipos corporativos.

### [YARA](https://github.com/VirusTotal/yara) [![Stars](https://img.shields.io/github/stars/VirusTotal/yara?style=social)](https://github.com/VirusTotal/yara)
- La herramienta estándar de reconocimiento de patrones para analistas de malware, identificando muestras basadas en reglas textuales o binarias.

### [Plaso (log2timeline)](https://github.com/log2timeline/plaso) [![Stars](https://img.shields.io/github/stars/log2timeline/plaso?style=social)](https://github.com/log2timeline/plaso)
- Motor en Python diseñado para extraer registros temporales y crear super-timelines completas a partir de artefactos forenses.

### [OSQuery](https://github.com/osquery/osquery) [![Stars](https://img.shields.io/github/stars/osquery/osquery?style=social)](https://github.com/osquery/osquery)
- Framework que expone el sistema operativo como una base de datos relacional, permitiendo consultas SQL para auditoría y monitoreo.
