# Security Standards, Compliance & Regulatory Frameworks

> Reference frameworks, benchmarks, maturity models, and consensus guidelines for organizational cyber defense.
> Frameworks de referência, benchmarks, modelos de maturidade e diretrizes consensuais para defesa cibernética organizacional.

---

### [SecurityStandards / security-standards](https://github.com/SecurityStandards/security-standards) [![Stars](https://img.shields.io/github/stars/SecurityStandards/security-standards?style=social)](https://github.com/SecurityStandards/security-standards)
- Canonical repository of cybersecurity policies, operational control procedures, compliance mappings (NIST, HIPAA, PCI, CIS), and interactive checklists.

### [NIST Cybersecurity Framework (CSF) 2.0](https://www.nist.gov/cyberframework)
- Globally adopted cybersecurity risk management framework organized across Govern, Identify, Protect, Detect, Respond, and Recover.

### [ISO/IEC 27001 & 27002:2022](https://www.iso.org/standard/27001)
- International benchmark standard specifying requirements for an Information Security Management System (ISMS) and security controls.

### [CIS Critical Security Controls v8](https://www.cisecurity.org/controls)
- Prioritized set of 18 essential cyber defense actions designed to mitigate the most pervasive cyber attacks.

### [PCI DSS v4.0.1](https://www.pcisecuritystandards.org/)
- Mandatory global security technical and operational requirements for entities storing, processing, or transmitting cardholder data.

### [OWASP Top 10](https://owasp.org/www-project-top-10/)
- Standard awareness document representing a broad consensus on the most critical security risks to web applications.

### [OWASP API Security Top 10](https://owasp.org/www-project-api-security/)
- Taxonomy of security vulnerabilities focused on modern APIs (Broken Object Level Authorization, Broken Authentication, etc.).

### [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
- Authoritative framework cataloging vulnerabilities in Large Language Models (Prompt Injection, Insecure Output Handling, Training Data Poisoning).

### [MITRE ATT&CK Matrix](https://attack.mitre.org/)
- Globally curated knowledge base of adversary tactics, techniques, and common knowledge based on real-world incident observations.
