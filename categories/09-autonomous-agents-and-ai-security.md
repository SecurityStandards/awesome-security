### [Shannon (agent-pentester)](https://github.com/SecurityStandards/agent-pentester) [![Stars](https://img.shields.io/github/stars/SecurityStandards/agent-pentester?style=social)](https://github.com/SecurityStandards/agent-pentester)
* 🇺🇸 **EN:** Autonomous AI penetration testing agent for web applications and APIs that inspects source repositories, identifies vectors, and confirms exploits.
* 🇧🇷 **PT:** Agente autônomo de pentest por IA para web e APIs que analisa código-fonte, mapeia vetores de ataque e confirma vulnerabilidades com exploits reais.
* 🇪🇸 **ES:** Agente autónomo de pentest con IA para aplicaciones web y APIs que analiza código fuente, planifica vectores y confirma exploits reales.

### [REA (agent-reverse-engineer)](https://github.com/SecurityStandards/agent-reverse-engineer) [![Stars](https://img.shields.io/github/stars/SecurityStandards/agent-reverse-engineer?style=social)](https://github.com/SecurityStandards/agent-reverse-engineer)
* 🇺🇸 **EN:** Autonomous reverse engineering agent capable of disassembling binaries, deconstructing application behaviors, and analyzing native code.
* 🇧🇷 **PT:** Agente autônomo de engenharia reversa capaz de descompilar binários, reconstruir comportamentos de sistemas e analisar código nativo.
* 🇪🇸 **ES:** Agente autónomo de ingeniería inversa capaz de descompilar binarios, reconstruir comportamientos de sistemas y analizar código nativo.

### [Cloudflare Security Audit Skill](https://github.com/SecurityStandards/skill-security-audit) [![Stars](https://img.shields.io/github/stars/SecurityStandards/skill-security-audit?style=social)](https://github.com/SecurityStandards/skill-security-audit)

* 🇧🇷 **PT:** Skill estruturada de auditoria de segurança em fases para coding-agents gerando achados de vulnerabilidade verificados por máquina (SARIF).
* 🇪🇸 **ES:** Habilidad estructurada de auditoría de seguridad en fases para agentes de código que genera hallazgos verificables por máquina (SARIF).
