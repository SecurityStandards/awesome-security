# SAST (Pruebas Estáticas de Seguridad de Aplicaciones)

> Analizadores que examinan código fuente, código de bytes o binarios en busca de debilidades de seguridad sin ejecutar el software.

---

### [Semgrep](https://github.com/semgrep/semgrep) [![Stars](https://img.shields.io/github/stars/semgrep/semgrep?style=social)](https://github.com/semgrep/semgrep)
- Motor de análisis estático rápido y políglota para encontrar errores, aplicar estándares de código y detectar vulnerabilidades mediante reglas legibles.

### [Bandit](https://github.com/PyCQA/bandit) [![Stars](https://img.shields.io/github/stars/PyCQA/bandit?style=social)](https://github.com/PyCQA/bandit)
- Herramienta de análisis estático orientada a la seguridad para código Python basada en la inspección del árbol de sintaxis abstracta (AST).

### [GoSec](https://github.com/securego/gosec) [![Stars](https://img.shields.io/github/stars/securego/gosec?style=social)](https://github.com/securego/gosec)
- Analizador de seguridad para Go que inspecciona el código fuente mediante AST para descubrir fallos de seguridad comunes.

### [Brakeman](https://github.com/presidentbeef/brakeman) [![Stars](https://img.shields.io/github/stars/presidentbeef/brakeman?style=social)](https://github.com/presidentbeef/brakeman)
- Escáner especializado de vulnerabilidades para aplicaciones Ruby on Rails que analiza el código directamente sin requerir configuración de la app.

### [Flawfinder](https://github.com/david-a-wheeler/flawfinder) [![Stars](https://img.shields.io/github/stars/david-a-wheeler/flawfinder?style=social)](https://github.com/david-a-wheeler/flawfinder)
- Escáner léxico de código fuente para C y C++ en busca de debilidades de seguridad conocidas (desbordamientos de búfer, format string).

### [NodeJsScan](https://github.com/ajinabraham/NodeJsScan) [![Stars](https://img.shields.io/github/stars/ajinabraham/NodeJsScan?style=social)](https://github.com/ajinabraham/NodeJsScan)
- Escáner de código estático adaptado para aplicaciones Node.js que busca patrones inseguros e inyecciones.

### [Checkstyle](https://github.com/checkstyle/checkstyle) [![Stars](https://img.shields.io/github/stars/checkstyle/checkstyle?style=social)](https://github.com/checkstyle/checkstyle)
- Herramienta de análisis estático que ayuda a los programadores a cumplir con convenciones de codificación segura en Java.

### [Opengrep](https://github.com/opengrep/opengrep) [![Stars](https://img.shields.io/github/stars/opengrep/opengrep?style=social)](https://github.com/opengrep/opengrep)
- Motor comunitario de análisis estático de código totalmente de código abierto para pruebas continuas de seguridad en pipelines.
