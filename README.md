## 🤝 Contributing

1. Review our engineering and commit guidelines in [AGENTS.md](AGENTS.md).
2. Proposed tools must be **open source** and actively maintained.
3. Every GitHub repository must feature the live shields star badge: `[![Stars](https://img.shields.io/github/stars/<owner>/<repo>?style=social)](https://github.com/owner/repo)`.
4. Submit a GPG-signed Pull Request!
