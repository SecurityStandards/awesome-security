### [Prowler](https://github.com/prowler-cloud/prowler) [![Stars](https://img.shields.io/github/stars/prowler-cloud/prowler?style=social)](https://github.com/prowler-cloud/prowler)
* 🇺🇸 **EN:** Open-source security tool for AWS, Azure, GCP, and Kubernetes assessments, audits, incident response, and continuous compliance checks against CIS Benchmarks.
* 🇧🇷 **PT:** Ferramenta open source para avaliações de segurança, auditoria e conformidade contínua em AWS, Azure, GCP e Kubernetes alinhada ao CIS Benchmarks.
* 🇪🇸 **ES:** Herramienta de código abierto para auditorías de seguridad y cumplimiento continuo en AWS, Azure, GCP y Kubernetes alineada con CIS Benchmarks.

### [Checkov](https://github.com/bridgecrewio/checkov) [![Stars](https://img.shields.io/github/stars/bridgecrewio/checkov?style=social)](https://github.com/bridgecrewio/checkov)
* 🇺🇸 **EN:** Static code analysis tool for Infrastructure as Code (IaC) scanning Terraform, CloudFormation, Kubernetes, Helm, ARM, and serverless configs.
* 🇧🇷 **PT:** Ferramenta de análise estática para Infraestrutura como Código (IaC) que analisa Terraform, CloudFormation, Kubernetes, Helm e ARM.
* 🇪🇸 **ES:** Herramienta de análisis estático para Infraestructura como Código (IaC) que analiza Terraform, CloudFormation, Kubernetes, Helm y ARM.

### [ScoutSuite](https://github.com/nccgroup/ScoutSuite) [![Stars](https://img.shields.io/github/stars/nccgroup/ScoutSuite?style=social)](https://github.com/nccgroup/ScoutSuite)
* 🇺🇸 **EN:** Multi-cloud security-auditing tool that gathers configuration data through cloud APIs to highlight risk areas in an intuitive HTML report.
* 🇧🇷 **PT:** Ferramenta de auditoria multi-cloud que coleta dados de configuração via APIs para destacar pontos de risco em relatórios HTML intuitivos.
* 🇪🇸 **ES:** Herramienta de auditoría multi-cloud que recopila datos de configuración mediante APIs para resaltar áreas de riesgo en informes HTML interactivos.

### [KICS (Keeping Infrastructure as Code Secure)](https://github.com/Checkmarx/kics) [![Stars](https://img.shields.io/github/stars/Checkmarx/kics?style=social)](https://github.com/Checkmarx/kics)
* 🇺🇸 **EN:** Open-source linter identifying vulnerabilities, compliance issues, and configuration defects across Terraform, Kubernetes, Ansible, and Dockerfile.
* 🇧🇷 **PT:** Linter open source identificando vulnerabilidades e falhas de conformidade em Terraform, Kubernetes, Ansible e Dockerfiles.
* 🇪🇸 **ES:** Linter de código abierto que identifica vulnerabilidades y fallos de cumplimiento en Terraform, Kubernetes, Ansible y Dockerfiles.

### [CloudFox](https://github.com/BishopFox/cloudfox) [![Stars](https://img.shields.io/github/stars/BishopFox/cloudfox?style=social)](https://github.com/BishopFox/cloudfox)
* 🇺🇸 **EN:** Command-line tool designed to help penetration testers and security engineers discover exploitable attack paths in AWS and Azure environments.
* 🇧🇷 **PT:** Ferramenta CLI projetada para ajudar pentesters e engenheiros de segurança a descobrir caminhos de ataque exploráveis em ambientes AWS e Azure.
* 🇪🇸 **ES:** Herramienta CLI diseñada para ayudar a pentesters e ingenieros de seguridad a descubrir rutas de ataque explotables en AWS y Azure.
