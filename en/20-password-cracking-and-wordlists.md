# Password Cracking, Hash Extraction & Wordlists

> GPU-accelerated hash crackers, password permutation engines, and essential wordlist collections.
> Quebradores de hash acelerados por GPU, motores de permutação de senhas e coleções essenciais de wordlists.

---

### [Hashcat](https://github.com/hashcat/hashcat) [![Stars](https://img.shields.io/github/stars/hashcat/hashcat?style=social)](https://github.com/hashcat/hashcat)
- The world's fastest and most advanced password recovery utility, leveraging OpenCL/CUDA acceleration for hundreds of hashing algorithms.

### [John the Ripper](https://github.com/openwall/john) [![Stars](https://img.shields.io/github/stars/openwall/john?style=social)](https://github.com/openwall/john)
- Open-source password security auditing and password recovery tool supporting dozens of hash types and automatic hash format identification.

### [SecLists](https://github.com/danielmiessler/SecLists) [![Stars](https://img.shields.io/github/stars/danielmiessler/SecLists?style=social)](https://github.com/danielmiessler/SecLists)
- The security tester's companion: the ultimate collection of multiple types of lists used during security assessments (usernames, passwords, URLs, fuzzing payloads).

### [CyberChef](https://github.com/gchq/CyberChef) [![Stars](https://img.shields.io/github/stars/gchq/CyberChef?style=social)](https://github.com/gchq/CyberChef)
- The Cyber Swiss Army Knife developed by GCHQ: a web app for encryption, encoding, compression, and data analysis in an interactive pipeline.
