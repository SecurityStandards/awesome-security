### [SecurityStandards / security-standards](https://github.com/SecurityStandards/security-standards) [![Stars](https://img.shields.io/github/stars/SecurityStandards/security-standards?style=social)](https://github.com/SecurityStandards/security-standards)
* 🇺🇸 **EN:** Canonical repository of cybersecurity policies, operational control procedures, compliance mappings (NIST, HIPAA, PCI, CIS), and interactive checklists.
* 🇧🇷 **PT:** Repositório canônico de políticas de segurança cibernética, procedimentos de controle operacional, mapeamentos de conformidade (NIST, HIPAA, PCI, CIS) e checklists interativos.
* 🇪🇸 **ES:** Repositorio canónico de políticas de ciberseguridad, procedimientos de control operativo, mapeos de cumplimiento (NIST, HIPAA, PCI, CIS) y listas de verificación interactivas.

### [NIST Cybersecurity Framework (CSF) 2.0](https://www.nist.gov/cyberframework)
* 🇺🇸 **EN:** Globally adopted cybersecurity risk management framework organized across Govern, Identify, Protect, Detect, Respond, and Recover.
* 🇧🇷 **PT:** Framework de gestão de riscos cibernéticos adotado mundialmente, estruturado em Governar, Identificar, Proteger, Detectar, Responder e Recuperar.
* 🇪🇸 **ES:** Marco de gestión de riesgos cibernéticos adoptado a nivel mundial, estructurado en Gobernar, Identificar, Proteger, Detectar, Responder y Recuperar.

### [ISO/IEC 27001 & 27002:2022](https://www.iso.org/standard/27001)
* 🇺🇸 **EN:** International benchmark standard specifying requirements for an Information Security Management System (ISMS) and security controls.
* 🇧🇷 **PT:** Padrão internacional de referência que especifica requisitos para um Sistema de Gestão de Segurança da Informação (SGSI) e seus controles.
* 🇪🇸 **ES:** Estándar internacional de referencia que especifica los requisitos para un Sistema de Gestión de Seguridad de la Información (SGSI) y sus controles.

### [CIS Critical Security Controls v8](https://www.cisecurity.org/controls)
* 🇺🇸 **EN:** Prioritized set of 18 essential cyber defense actions designed to mitigate the most pervasive cyber attacks.
* 🇧🇷 **PT:** Conjunto priorizado de 18 salvaguardas essenciais de defesa cibernética projetadas para mitigar os ataques cibernéticos mais comuns.
* 🇪🇸 **ES:** Conjunto priorizado de 18 salvaguardas esenciales de ciberdefensa diseñadas para mitigar los ciberataques más extendidos.

### [PCI DSS v4.0.1](https://www.pcisecuritystandards.org/)
* 🇺🇸 **EN:** Mandatory global security technical and operational requirements for entities storing, processing, or transmitting cardholder data.
* 🇧🇷 **PT:** Requisitos técnicos e operacionais obrigatórios para entidades que armazenam, processam ou transmitem dados de portadores de cartão.
* 🇪🇸 **ES:** Requisitos técnicos y operativos globales obligatorios para entidades que almacenan, procesan o transmiten datos de titulares de tarjetas.

### [OWASP Top 10](https://owasp.org/www-project-top-10/)
* 🇺🇸 **EN:** Standard awareness document representing a broad consensus on the most critical security risks to web applications.
* 🇧🇷 **PT:** Documento de referência que representa o consenso global sobre os riscos de segurança mais críticos em aplicações web.
* 🇪🇸 **ES:** Documento de referencia que representa el consenso global sobre los riesgos de seguridad más críticos en aplicaciones web.

### [OWASP API Security Top 10](https://owasp.org/www-project-api-security/)
* 🇺🇸 **EN:** Taxonomy of security vulnerabilities focused on modern APIs (Broken Object Level Authorization, Broken Authentication, etc.).
* 🇧🇷 **PT:** Taxonomia de vulnerabilidades focada em APIs modernas (autorização quebrada no nível de objeto, falhas de autenticação, etc.).
* 🇪🇸 **ES:** Taxonomía de vulnerabilidades de seguridad enfocada en APIs modernas (autorización rota a nivel de objeto, fallas de autenticación, etc.).

### [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
* 🇺🇸 **EN:** Authoritative framework cataloging vulnerabilities in Large Language Models (Prompt Injection, Insecure Output Handling, Training Data Poisoning).
* 🇧🇷 **PT:** Guia autoritativo catalogando vulnerabilidades em modelos de linguagem grande (Prompt Injection, manipulação insegura de saídas, envenenamento de dados).
* 🇪🇸 **ES:** Guía autorizada que cataloga vulnerabilidades en modelos de lenguaje grande (Prompt Injection, manejo inseguro de salidas, envenenamiento de datos).

### [MITRE ATT&CK Matrix](https://attack.mitre.org/)
* 🇺🇸 **EN:** Globally curated knowledge base of adversary tactics, techniques, and common knowledge based on real-world incident observations.
* 🇧🇷 **PT:** Base de conhecimento global sobre táticas, técnicas e procedimentos adversários fundamentada em observações reais de incidentes.
* 🇪🇸 **ES:** Base de conocimiento global sobre tácticas, técnicas y procedimientos de adversarios basada en observaciones reales de incidentes.
