# Plano de Implementação: Awesome Security Curated List

## 1. Estrutura e Taxonomia do Conteúdo

1. **Frameworks & Padrões Regulatórios** (NIST, ISO, CIS, PCI DSS, etc.)
2. **SAST (Static Application Security Testing)**: Semgrep, Bandit, SonarQube Community, Brakeman, GoSec, Flawfinder, etc.
3. **DAST (Dynamic Application Security Testing)**: OWASP ZAP, Nuclei, Nikto, Wapiti, Arachni, Caido, etc.
4. **SCA (Software Composition Analysis)**: Dependency-Check, OSV-Scanner, Syft, Grype, Trivy, Reticulated, etc.
5. **OSINT (Open Source Intelligence)**: theHarvester, Sherlock, SpiderFoot, Recon-ng, Amass, Maltego, Photon, etc.
6. **Secrets Detection**: TruffleHog, Gitleaks, detect-secrets, Whispers, etc.
7. **Container & Cloud Security**: Trivy, Prowler, ScoutSuite, Checkov, Falco, Kube-bench, Kube-hunter, etc.
8. **Network Security & Recon**: Nmap, Masscan, RustScan, ProjectDiscovery subfinder, naabu, httpx, etc.
9. **AI & Autonomous Security Agents**: Shannon, REA, Cloudflare Security Audit Skill, Auto-pentester, LLM Top 10.
10. **SIEM, SOC & Incident Response**: Wazuh, Suricata, Zeek, Velociraptor, TheHive, MISP.
