# SCA (Análisis de Composición de Software) y SBOM

> Herramientas para detectar vulnerabilidades conocidas (CVEs), dependencias obsoletas y cumplimiento de licencias de código abierto, generando SBOMs.

---

### [Trivy](https://github.com/aquasecurity/trivy) [![Stars](https://img.shields.io/github/stars/aquasecurity/trivy?style=social)](https://github.com/aquasecurity/trivy)
- Escáner de seguridad completo y versátil para imágenes de contenedores, sistemas de archivos, repositorios Git, máquinas virtuales y Kubernetes.

### [OSV-Scanner](https://github.com/google/osv-scanner) [![Stars](https://img.shields.io/github/stars/google/osv-scanner?style=social)](https://github.com/google/osv-scanner)
- Escáner de vulnerabilidades desarrollado por Google que consulta la base de datos distribuida Open Source Vulnerabilities (OSV).

### [Syft](https://github.com/anchore/syft) [![Stars](https://img.shields.io/github/stars/anchore/syft?style=social)](https://github.com/anchore/syft)
- Herramienta CLI y librería en Go para generar Software Bill of Materials (SBOM) a partir de contenedores y sistemas de archivos.

### [Grype](https://github.com/anchore/grype) [![Stars](https://img.shields.io/github/stars/anchore/grype?style=social)](https://github.com/anchore/grype)
- Escáner rápido de vulnerabilidades para imágenes de contenedores y sistemas de archivos, diseñado para trabajar en conjunto con SBOMs de Syft.

### [OWASP Dependency-Check](https://github.com/jeremylong/DependencyCheck) [![Stars](https://img.shields.io/github/stars/jeremylong/DependencyCheck?style=social)](https://github.com/jeremylong/DependencyCheck)
- Utilidad tradicional de SCA que identifica dependencias de proyectos y verifica la presencia de CVEs públicas conocidas.

### [Retire.js](https://github.com/RetireJS/retire.js) [![Stars](https://img.shields.io/github/stars/RetireJS/retire.js?style=social)](https://github.com/RetireJS/retire.js)
- Escáner que detecta el uso de librerías JavaScript vulnerables y módulos Node.js en código frontend y backend.
