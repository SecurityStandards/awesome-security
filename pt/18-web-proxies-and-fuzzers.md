# Scanners de Vulnerabilidade Web, Proxies e Segurança de APIs

> Descoberta de conteúdo oculto, motores de fuzzing, proxies de interceptação, scanners de CMS e ferramentas de segurança de API.

---

### [ffuf (Fuzz Faster U Fool)](https://github.com/ffuf/ffuf) [![Stars](https://img.shields.io/github/stars/ffuf/ffuf?style=social)](https://github.com/ffuf/ffuf)
- Fuzzer web veloz escrito em Go projetado para descobrir diretórios ocultos, virtual hosts e parâmetros com alta concorrência.

### [Gobuster](https://github.com/OJ/gobuster) [![Stars](https://img.shields.io/github/stars/OJ/gobuster?style=social)](https://github.com/OJ/gobuster)
- Ferramenta clássica em Go para força bruta de diretórios, arquivos, subdomínios DNS e virtual hosts em servidores web.

### [WPScan](https://github.com/wpscanteam/wpscan) [![Stars](https://img.shields.io/github/stars/wpscanteam/wpscan?style=social)](https://github.com/wpscanteam/wpscan)
- Scanner de segurança dedicado para WordPress analisando o núcleo, temas e plugins contra bases de vulnerabilidades conhecidas.

### [mitmproxy](https://github.com/mitmproxy/mitmproxy) [![Stars](https://img.shields.io/github/stars/mitmproxy/mitmproxy?style=social)](https://github.com/mitmproxy/mitmproxy)
- Proxy de interceptação HTTP/HTTPS interativo com suporte completo a scripts Python para análise e modificação de tráfego em tempo real.

### [JWT Tool](https://github.com/ticarpi/jwt_tool) [![Stars](https://img.shields.io/github/stars/ticarpi/jwt_tool?style=social)](https://github.com/ticarpi/jwt_tool)
- Toolkit abrangente para validar, falsificar, auditar e manipular JSON Web Tokens (JWT) durante testes de invasão em APIs.
