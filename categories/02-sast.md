# SAST (Static Application Security Testing)
# SAST (Testes Estáticos de Segurança de Aplicações)
# SAST (Pruebas Estáticas de Seguridad de Aplicaciones)

> Analyzers that examine source code, byte code, or binary code for security weaknesses and vulnerabilities without executing the software.
> Analisadores que examinam código-fonte, bytecode ou binários em busca de vulnerabilidades de segurança sem executar o software.
> Analizadores que examinan código fuente, código de bytes o binarios en busca de debilidades de seguridad sin ejecutar el software.

---

### [Semgrep](https://github.com/semgrep/semgrep) [![Stars](https://img.shields.io/github/stars/semgrep/semgrep?style=social)](https://github.com/semgrep/semgrep)
* 🇺🇸 **EN:** Fast, polyglot static analysis engine for finding bugs, enforcing code standards, and detecting vulnerabilities with human-readable rules.
* 🇧🇷 **PT:** Motor de análise estática rápido e poliglota para encontrar bugs, aplicar padrões de código e detectar vulnerabilidades via regras legíveis.
* 🇪🇸 **ES:** Motor de análisis estático rápido y políglota para encontrar errores, aplicar estándares de código y detectar vulnerabilidades mediante reglas legibles.

### [Bandit](https://github.com/PyCQA/bandit) [![Stars](https://img.shields.io/github/stars/PyCQA/bandit?style=social)](https://github.com/PyCQA/bandit)
* 🇺🇸 **EN:** Security-oriented static analysis tool for Python code based on AST inspection.
* 🇧🇷 **PT:** Ferramenta de análise estática orientada à segurança para código Python baseada na inspeção da árvore sintática abstrata (AST).
* 🇪🇸 **ES:** Herramienta de análisis estático orientada a la seguridad para código Python basada en la inspección del árbol de sintaxis abstracta (AST).

### [GoSec](https://github.com/securego/gosec) [![Stars](https://img.shields.io/github/stars/securego/gosec?style=social)](https://github.com/securego/gosec)
* 🇺🇸 **EN:** Go security checker that inspects source code by parsing AST to uncover common security problems.
* 🇧🇷 **PT:** Verificador de segurança para Go que inspeciona o código-fonte via AST para descobrir falhas de segurança recorrentes.
* 🇪🇸 **ES:** Analizador de seguridad para Go que inspecciona el código fuente mediante AST para descubrir fallos de seguridad comunes.

### [Brakeman](https://github.com/presidentbeef/brakeman) [![Stars](https://img.shields.io/github/stars/presidentbeef/brakeman?style=social)](https://github.com/presidentbeef/brakeman)
* 🇺🇸 **EN:** Specialized vulnerability scanner for Ruby on Rails applications that scans code directly without requiring application setup.
* 🇧🇷 **PT:** Scanner especializado de vulnerabilidades para aplicações Ruby on Rails que analisa o código diretamente sem exigir setup da aplicação.
* 🇪🇸 **ES:** Escáner especializado de vulnerabilidades para aplicaciones Ruby on Rails que analiza el código directamente sin requerir configuración de la app.

### [Flawfinder](https://github.com/david-a-wheeler/flawfinder) [![Stars](https://img.shields.io/github/stars/david-a-wheeler/flawfinder?style=social)](https://github.com/david-a-wheeler/flawfinder)
* 🇺🇸 **EN:** Lexical source code scanner for C and C++ looking for known security weaknesses (e.g. buffer overflows, format string vulnerabilities).
* 🇧🇷 **PT:** Scanner de código-fonte léxico para C e C++ procurando por fraquezas conhecidas de segurança (buffer overflows, format string).
* 🇪🇸 **ES:** Escáner léxico de código fuente para C y C++ en busca de debilidades de seguridad conocidas (desbordamientos de búfer, format string).

### [NodeJsScan](https://github.com/ajinabraham/NodeJsScan) [![Stars](https://img.shields.io/github/stars/ajinabraham/NodeJsScan?style=social)](https://github.com/ajinabraham/NodeJsScan)

* 🇪🇸 **ES:** Escáner de código estático adaptado para aplicaciones Node.js que busca patrones inseguros e inyecciones.
