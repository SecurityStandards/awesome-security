### [Hashcat](https://github.com/hashcat/hashcat) [![Stars](https://img.shields.io/github/stars/hashcat/hashcat?style=social)](https://github.com/hashcat/hashcat)
* 🇺🇸 **EN:** The world's fastest and most advanced password recovery utility, leveraging OpenCL/CUDA acceleration for hundreds of hashing algorithms.
* 🇧🇷 **PT:** O recuperador de senhas mais rápido e avançado do mundo, utilizando aceleração via GPU (OpenCL/CUDA) para centenas de algoritmos de hash.
* 🇪🇸 **ES:** El recuperador de contraseñas más rápido y avanzado del mundo, que utiliza aceleración por GPU para cientos de algoritmos de hash.

### [John the Ripper](https://github.com/openwall/john) [![Stars](https://img.shields.io/github/stars/openwall/john?style=social)](https://github.com/openwall/john)
* 🇺🇸 **EN:** Open-source password security auditing and password recovery tool supporting dozens of hash types and automatic hash format identification.
* 🇧🇷 **PT:** Ferramenta open source de auditoria e recuperação de senhas com suporte a dezenas de tipos de hash e detecção automática de formatos.
* 🇪🇸 **ES:** Herramienta de código abierto de auditoría y recuperación de contraseñas con soporte para docenas de tipos de hash y detección automática.

### [SecLists](https://github.com/danielmiessler/SecLists) [![Stars](https://img.shields.io/github/stars/danielmiessler/SecLists?style=social)](https://github.com/danielmiessler/SecLists)
* 🇺🇸 **EN:** The security tester's companion: the ultimate collection of multiple types of lists used during security assessments (usernames, passwords, URLs, fuzzing payloads).
* 🇧🇷 **PT:** A coleção definitiva de wordlists da comunidade de segurança: nomes de usuários, senhas, URLs, payloads de fuzzing e padrões de injeção.
* 🇪🇸 **ES:** La colección definitiva de listas para pruebas de seguridad: nombres de usuario, contraseñas, URLs, cargas de fuzzing y patrones de inyección.

### [CyberChef](https://github.com/gchq/CyberChef) [![Stars](https://img.shields.io/github/stars/gchq/CyberChef?style=social)](https://github.com/gchq/CyberChef)
* 🇺🇸 **EN:** The Cyber Swiss Army Knife developed by GCHQ: a web app for encryption, encoding, compression, and data analysis in an interactive pipeline.
* 🇧🇷 **PT:** O canivete suíço digital desenvolvido pelo GCHQ: aplicação web para decodificação, criptografia, descompressão e análise de dados.
* 🇪🇸 **ES:** La navaja suiza digital desarrollada por GCHQ: aplicación web para decodificación, cifrado, descompresión y análisis de datos en un flujo interactivo.
