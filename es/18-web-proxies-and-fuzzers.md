# Escáneres de Vulnerabilidades Web, Proxies y Seguridad de APIs

> Descubrimiento de contenido oculto, motores de fuzzing, proxies de intercepción, escáneres de CMS y herramientas de seguridad de API.

---

### [ffuf (Fuzz Faster U Fool)](https://github.com/ffuf/ffuf) [![Stars](https://img.shields.io/github/stars/ffuf/ffuf?style=social)](https://github.com/ffuf/ffuf)
- Fuzzer web rápido en Go diseñado para descubrir directorios ocultos, virtual hosts y parámetros con alta concurrencia.

### [Gobuster](https://github.com/OJ/gobuster) [![Stars](https://img.shields.io/github/stars/OJ/gobuster?style=social)](https://github.com/OJ/gobuster)
- Herramienta clásica en Go para fuerza bruta de directorios, archivos, subdominios DNS y virtual hosts en servidores web.

### [WPScan](https://github.com/wpscanteam/wpscan) [![Stars](https://img.shields.io/github/stars/wpscanteam/wpscan?style=social)](https://github.com/wpscanteam/wpscan)
- Escáner de seguridad dedicado para WordPress que analiza el núcleo, temas y plugins frente a bases de vulnerabilidades conocidas.

### [mitmproxy](https://github.com/mitmproxy/mitmproxy) [![Stars](https://img.shields.io/github/stars/mitmproxy/mitmproxy?style=social)](https://github.com/mitmproxy/mitmproxy)
- Proxy de intercepción HTTP/HTTPS interactivo con soporte completo para scripts en Python para análisis y modificación de tráfico en tiempo real.

### [JWT Tool](https://github.com/ticarpi/jwt_tool) [![Stars](https://img.shields.io/github/stars/ticarpi/jwt_tool?style=social)](https://github.com/ticarpi/jwt_tool)
- Toolkit completo para validar, falsificar, auditar y manipular JSON Web Tokens (JWT) durante pruebas de penetración en APIs.
