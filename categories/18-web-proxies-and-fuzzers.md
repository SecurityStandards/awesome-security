### [ffuf (Fuzz Faster U Fool)](https://github.com/ffuf/ffuf) [![Stars](https://img.shields.io/github/stars/ffuf/ffuf?style=social)](https://github.com/ffuf/ffuf)
* 🇺🇸 **EN:** Fast web fuzzer written in Go designed to discover hidden endpoints, directories, virtual hosts, and parameters with high concurrency.
* 🇧🇷 **PT:** Fuzzer web veloz escrito em Go projetado para descobrir diretórios ocultos, virtual hosts e parâmetros com alta concorrência.
* 🇪🇸 **ES:** Fuzzer web rápido en Go diseñado para descubrir directorios ocultos, virtual hosts y parámetros con alta concurrencia.

### [Gobuster](https://github.com/OJ/gobuster) [![Stars](https://img.shields.io/github/stars/OJ/gobuster?style=social)](https://github.com/OJ/gobuster)
* 🇺🇸 **EN:** Classic tool written in Go to brute-force URIs (directories and files) in web sites, DNS subdomains, and virtual host names.
* 🇧🇷 **PT:** Ferramenta clássica em Go para força bruta de diretórios, arquivos, subdomínios DNS e virtual hosts em servidores web.
* 🇪🇸 **ES:** Herramienta clásica en Go para fuerza bruta de directorios, archivos, subdominios DNS y virtual hosts en servidores web.

### [WPScan](https://github.com/wpscanteam/wpscan) [![Stars](https://img.shields.io/github/stars/wpscanteam/wpscan?style=social)](https://github.com/wpscanteam/wpscan)
* 🇺🇸 **EN:** Dedicated WordPress security scanner scanning core installations, themes, and plugins against known CVE databases.
* 🇧🇷 **PT:** Scanner de segurança dedicado para WordPress analisando o núcleo, temas e plugins contra bases de vulnerabilidades conhecidas.
* 🇪🇸 **ES:** Escáner de seguridad dedicado para WordPress que analiza el núcleo, temas y plugins frente a bases de vulnerabilidades conocidas.

### [mitmproxy](https://github.com/mitmproxy/mitmproxy) [![Stars](https://img.shields.io/github/stars/mitmproxy/mitmproxy?style=social)](https://github.com/mitmproxy/mitmproxy)
* 🇺🇸 **EN:** An interactive, SSL/TLS-capable intercepting HTTP proxy for penetration testers, security researchers, and software engineers with full Python scripting.
* 🇧🇷 **PT:** Proxy de interceptação HTTP/HTTPS interativo com suporte completo a scripts Python para análise e modificação de tráfego em tempo real.
* 🇪🇸 **ES:** Proxy de intercepción HTTP/HTTPS interactivo con soporte completo para scripts en Python para análisis y modificación de tráfico en tiempo real.

### [JWT Tool](https://github.com/ticarpi/jwt_tool) [![Stars](https://img.shields.io/github/stars/ticarpi/jwt_tool?style=social)](https://github.com/ticarpi/jwt_tool)
* 🇺🇸 **EN:** Comprehensive toolkit for validating, forging, scanning, and tampering with JSON Web Tokens (JWT) during API penetration testing.
* 🇧🇷 **PT:** Toolkit abrangente para validar, falsificar, auditar e manipular JSON Web Tokens (JWT) durante testes de invasão em APIs.
* 🇪🇸 **ES:** Toolkit completo para validar, falsificar, auditar y manipular JSON Web Tokens (JWT) durante pruebas de penetración en APIs.
