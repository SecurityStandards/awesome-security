### [Falco](https://github.com/falcosecurity/falco) [![Stars](https://img.shields.io/github/stars/falcosecurity/falco?style=social)](https://github.com/falcosecurity/falco)

* 🇧🇷 **PT:** Padrão de fato em segurança de tempo de execução cloud-native, utilizando eBPF para detectar comportamentos anômalos e intrusões em tempo real.
* 🇪🇸 **ES:** Estándar de facto en seguridad de tiempo de ejecución cloud-native, que utiliza eBPF para detectar comportamientos anómalos e intrusiones en tiempo real.

### [kube-bench](https://github.com/aquasecurity/kube-bench) [![Stars](https://img.shields.io/github/stars/aquasecurity/kube-bench?style=social)](https://github.com/aquasecurity/kube-bench)
* 🇺🇸 **EN:** Automated Go tool that checks whether Kubernetes is deployed securely by executing tests documented in the CIS Kubernetes Benchmark.
* 🇧🇷 **PT:** Ferramenta automatizada em Go que verifica se o Kubernetes está implantado com segurança executando testes do CIS Kubernetes Benchmark.
* 🇪🇸 **ES:** Herramienta automatizada en Go que verifica si Kubernetes está implementado de forma segura ejecutando pruebas del CIS Kubernetes Benchmark.

### [kube-hunter](https://github.com/aquasecurity/kube-hunter) [![Stars](https://img.shields.io/github/stars/aquasecurity/kube-hunter?style=social)](https://github.com/aquasecurity/kube-hunter)
* 🇺🇸 **EN:** Hunts for security weaknesses and vulnerabilities in Kubernetes clusters from both inside and outside the network perimeter.
* 🇧🇷 **PT:** Rastreia fraquezas de segurança e vulnerabilidades em clusters Kubernetes a partir de perspectivas internas e externas à rede.
* 🇪🇸 **ES:** Rastrea debilidades de seguridad y vulnerabilidades en clústeres de Kubernetes desde perspectivas internas y externas a la red.

### [Cosign (Sigstore)](https://github.com/sigstore/cosign) [![Stars](https://img.shields.io/github/stars/sigstore/cosign?style=social)](https://github.com/sigstore/cosign)
* 🇺🇸 **EN:** Container signing, verification, and key management integrated into OCI registries for verifiable software supply chains.
* 🇧🇷 **PT:** Assinatura de containers, verificação e gestão de chaves criptográficas em registros OCI para cadeias de suprimentos de software seguras.
* 🇪🇸 **ES:** Firma de contenedores, verificación y gestión de claves en registros OCI para cadenas de suministro de software verificables.

### [Hadolint](https://github.com/hadolint/hadolint) [![Stars](https://img.shields.io/github/stars/hadolint/hadolint?style=social)](https://github.com/hadolint/hadolint)
* 🇺🇸 **EN:** Smart Dockerfile linter enforcing best practices and checking syntax against ShellCheck to prevent insecure image building.
* 🇧🇷 **PT:** Linter inteligente de Dockerfile que aplica boas práticas de segurança e valida comandos com ShellCheck para evitar imagens vulneráveis.
* 🇪🇸 **ES:** Linter inteligente para Dockerfiles que aplica buenas prácticas y valida sintaxis con ShellCheck para evitar imágenes inseguras.
