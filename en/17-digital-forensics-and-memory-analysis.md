# Digital Forensics, Memory Analysis & Incident Handling

> Live response artifacts acquisition, memory dump extraction, timeline generation, and filesystem forensic inspection.
> Coleta de artefatos em sistemas ativos, extração e análise de dumps de memória RAM, geração de linhas do tempo e perícia em sistemas de arquivos.

---

### [Volatility 3](https://github.com/volatilityfoundation/volatility3) [![Stars](https://img.shields.io/github/stars/volatilityfoundation/volatility3?style=social)](https://github.com/volatilityfoundation/volatility3)
- The world's most widely used memory forensics framework for extracting digital artifacts from volatile memory (RAM) samples.

### [Autopsy](https://github.com/sleuthkit/autopsy) [![Stars](https://img.shields.io/github/stars/sleuthkit/autopsy?style=social)](https://github.com/sleuthkit/autopsy)
- Premier open-source digital forensics platform and graphical interface to The Sleuth Kit used by law enforcement, military, and corporate examiners.

### [YARA](https://github.com/VirusTotal/yara) [![Stars](https://img.shields.io/github/stars/VirusTotal/yara?style=social)](https://github.com/VirusTotal/yara)
- The pattern-matching Swiss Army knife for malware researchers, identifying and classifying malware samples based on textual or binary patterns.

### [Plaso (log2timeline)](https://github.com/log2timeline/plaso) [![Stars](https://img.shields.io/github/stars/log2timeline/plaso?style=social)](https://github.com/log2timeline/plaso)
- Python-based engine designed to extract timestamps and create comprehensive super-timelines from computer forensics artifacts.

### [OSQuery](https://github.com/osquery/osquery) [![Stars](https://img.shields.io/github/stars/osquery/osquery?style=social)](https://github.com/osquery/osquery)
- SQL-powered operating system instrumentation, monitoring, and analytics framework exposing an OS as a high-performance relational database.
