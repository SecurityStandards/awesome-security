# Estándares de Seguridad, Cumplimiento y Marcos Regulatorios

> Marcos de referencia, benchmarks, modelos de madurez y directrices de consenso para la defensa cibernética organizacional.

---

### [SecurityStandards / security-standards](https://github.com/SecurityStandards/security-standards) [![Stars](https://img.shields.io/github/stars/SecurityStandards/security-standards?style=social)](https://github.com/SecurityStandards/security-standards)
- Repositorio canónico de políticas de ciberseguridad, procedimientos de control operativo, mapeos de cumplimiento (NIST, HIPAA, PCI, CIS) y listas de verificación interactivas.

### [NIST Cybersecurity Framework (CSF) 2.0](https://www.nist.gov/cyberframework)
- Marco de gestión de riesgos cibernéticos adoptado a nivel mundial, estructurado en Gobernar, Identificar, Proteger, Detectar, Responder y Recuperar.

### [ISO/IEC 27001 & 27002:2022](https://www.iso.org/standard/27001)
- Estándar internacional de referencia que especifica los requisitos para un Sistema de Gestión de Seguridad de la Información (SGSI) y sus controles.

### [CIS Critical Security Controls v8](https://www.cisecurity.org/controls)
- Conjunto priorizado de 18 salvaguardas esenciales de ciberdefensa diseñadas para mitigar los ciberataques más extendidos.

### [PCI DSS v4.0.1](https://www.pcisecuritystandards.org/)
- Requisitos técnicos y operativos globales obligatorios para entidades que almacenan, procesan o transmiten datos de titulares de tarjetas.

### [OWASP Top 10](https://owasp.org/www-project-top-10/)
- Documento de referencia que representa el consenso global sobre los riesgos de seguridad más críticos en aplicaciones web.

### [OWASP API Security Top 10](https://owasp.org/www-project-api-security/)
- Taxonomía de vulnerabilidades de seguridad enfocada en APIs modernas (autorización rota a nivel de objeto, fallas de autenticación, etc.).

### [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
- Guía autorizada que cataloga vulnerabilidades en modelos de lenguaje grande (Prompt Injection, manejo inseguro de salidas, envenenamiento de datos).

### [MITRE ATT&CK Matrix](https://attack.mitre.org/)
- Base de conocimiento global sobre tácticas, técnicas y procedimientos de adversarios basada en observaciones reales de incidentes.
