# Criptografía, Infraestructura de Clave Pública (PKI) y Gestión de Secretos

> Librerías criptográficas, herramientas de autoridad certificadora (CA), mutual TLS y bóvedas de gestión de secretos.

---

### [Step-CA (Smallstep)](https://github.com/smallstep/certificates) [![Stars](https://img.shields.io/github/stars/smallstep/certificates?style=social)](https://github.com/smallstep/certificates)
- Autoridad de Certificación privada y toolkit de PKI para DevOps, protegiendo redes internas, microservicios y dispositivos con mTLS automatizado.

### [Vault (OpenBao)](https://github.com/openbao/openbao) [![Stars](https://img.shields.io/github/stars/openbao/openbao?style=social)](https://github.com/openbao/openbao)
- Software de código abierto comunitario para la gestión de secretos, certificados, tokens y claves de cifrado en sistemas distribuidos.

### [Age](https://github.com/FiloSottile/age) [![Stars](https://img.shields.io/github/stars/FiloSottile/age?style=social)](https://github.com/FiloSottile/age)
- Herramienta y librería moderna, simple y segura de cifrado de archivos con claves concisas, sin configuraciones complejas y filosofía UNIX.

### [SOPS (Secrets OPerationS)](https://github.com/getsops/sops) [![Stars](https://img.shields.io/github/stars/getsops/sops?style=social)](https://github.com/getsops/sops)
- Editor simple y flexible de archivos cifrados con soporte para YAML, JSON y ENV integrado con AWS KMS, GCP KMS, Azure Key Vault y age.
