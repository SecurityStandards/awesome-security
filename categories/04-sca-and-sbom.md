# SCA (Análisis de Composición de Software) y SBOM

> Tools for detecting known vulnerabilities (CVEs), outdated dependencies, and open-source license compliance while generating Software Bills of Materials (SBOMs).
> Ferramentas para detectar vulnerabilidades conhecidas (CVEs), dependências desatualizadas e licenças de código aberto, além de gerar SBOMs.
> Herramientas para detectar vulnerabilidades conocidas (CVEs), dependencias obsoletas y cumplimiento de licencias de código abierto, generando SBOMs.

---

### [Trivy](https://github.com/aquasecurity/trivy) [![Stars](https://img.shields.io/github/stars/aquasecurity/trivy?style=social)](https://github.com/aquasecurity/trivy)
* 🇺🇸 **EN:** Comprehensive and versatile security scanner for container images, file systems, Git repositories, virtual machine images, and Kubernetes.
* 🇧🇷 **PT:** Scanner de segurança abrangente e versátil para imagens de container, sistemas de arquivos, repositórios Git, imagens de VM e Kubernetes.
* 🇪🇸 **ES:** Escáner de seguridad completo y versátil para imágenes de contenedores, sistemas de archivos, repositorios Git, máquinas virtuales y Kubernetes.

### [OSV-Scanner](https://github.com/google/osv-scanner) [![Stars](https://img.shields.io/github/stars/google/osv-scanner?style=social)](https://github.com/google/osv-scanner)
* 🇺🇸 **EN:** Vulnerability scanner developed by Google that leverages the distributed Open Source Vulnerabilities (OSV) database.
* 🇧🇷 **PT:** Scanner de vulnerabilidades desenvolvido pelo Google que consulta a base distribuída Open Source Vulnerabilities (OSV).
* 🇪🇸 **ES:** Escáner de vulnerabilidades desarrollado por Google que consulta la base de datos distribuida Open Source Vulnerabilities (OSV).

### [Syft](https://github.com/anchore/syft) [![Stars](https://img.shields.io/github/stars/anchore/syft?style=social)](https://github.com/anchore/syft)
* 🇺🇸 **EN:** CLI tool and Go library for generating a Software Bill of Materials (SBOM) from container images and filesystems (SPDX, CycloneDX formats).
* 🇧🇷 **PT:** Ferramenta CLI e biblioteca em Go para geração de Software Bill of Materials (SBOM) a partir de containers e arquivos (SPDX, CycloneDX).
* 🇪🇸 **ES:** Herramienta CLI y librería en Go para generar Software Bill of Materials (SBOM) a partir de contenedores y sistemas de archivos.

### [Grype](https://github.com/anchore/grype) [![Stars](https://img.shields.io/github/stars/anchore/grype?style=social)](https://github.com/anchore/grype)
* 🇺🇸 **EN:** Fast vulnerability scanner for container images and filesystems, natively designed to work seamlessly with Syft SBOMs.
* 🇧🇷 **PT:** Scanner rápido de vulnerabilidades para imagens de container e sistemas de arquivos, projetado para trabalhar em conjunto com SBOMs do Syft.
* 🇪🇸 **ES:** Escáner rápido de vulnerabilidades para imágenes de contenedores y sistemas de archivos, diseñado para trabajar en conjunto con SBOMs de Syft.

### [OWASP Dependency-Check](https://github.com/jeremylong/DependencyCheck) [![Stars](https://img.shields.io/github/stars/jeremylong/DependencyCheck?style=social)](https://github.com/jeremylong/DependencyCheck)
* 🇺🇸 **EN:** Traditional Software Composition Analysis utility identifying project dependencies and checking for known publicly disclosed CVEs.
* 🇧🇷 **PT:** Utilitário tradicional de SCA que identifica dependências de projetos e verifica a presença de CVEs públicas conhecidas.
* 🇪🇸 **ES:** Utilidad tradicional de SCA que identifica dependencias de proyectos y verifica la presencia de CVEs públicas conocidas.

### [Retire.js](https://github.com/RetireJS/retire.js) [![Stars](https://img.shields.io/github/stars/RetireJS/retire.js?style=social)](https://github.com/RetireJS/retire.js)
* 🇺🇸 **EN:** Scanner detecting the use of vulnerable JavaScript libraries and Node.js modules in web frontends and backend code.
* 🇧🇷 **PT:** Scanner detectando o uso de bibliotecas JavaScript vulneráveis e módulos Node.js em frontends e backends.
* 🇪🇸 **ES:** Escáner que detecta el uso de librerías JavaScript vulnerables y módulos Node.js en código frontend y backend.
