# Red Teaming, Adversary Emulation & C2 Frameworks

> Post-exploitation command and control (C2), adversary emulation platforms, and credential dumping utilities.
> Comando e controle (C2) pós-exploração, plataformas de emulação de adversários e utilitários de extração de credenciais.

---

### [Metasploit Framework](https://github.com/rapid7/metasploit-framework) [![Stars](https://img.shields.io/github/stars/rapid7/metasploit-framework?style=social)](https://github.com/rapid7/metasploit-framework)
- The world's most widely used penetration testing platform providing verified exploits, payload generation, and automation modules.

### [Caldera (MITRE)](https://github.com/mitre/caldera) [![Stars](https://img.shields.io/github/stars/mitre/caldera?style=social)](https://github.com/mitre/caldera)
- Cyber adversary emulation software platform built by MITRE directly mapped to the ATT&CK framework for automated red-team exercises.

### [Sliver](https://github.com/BishopFox/sliver) [![Stars](https://img.shields.io/github/stars/BishopFox/sliver?style=social)](https://github.com/BishopFox/sliver)
- Open-source cross-platform adversary emulation and Command and Control (C2) framework developed by BishopFox in Go supporting mTLS, WireGuard, and DNS.

### [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) [![Stars](https://img.shields.io/github/stars/redcanaryco/atomic-red-team?style=social)](https://github.com/redcanaryco/atomic-red-team)
- Library of simple, open-source, automated atomic tests mapped to the MITRE ATT&CK framework for validating defensive security controls.

### [Mimikatz](https://github.com/gentilkiwi/mimikatz) [![Stars](https://img.shields.io/github/stars/gentilkiwi/mimikatz?style=social)](https://github.com/gentilkiwi/mimikatz)
- Seminal tool that extracts plaintext passwords, hash digests, PIN codes, and kerberos tickets from memory on Windows systems (LSASS).
