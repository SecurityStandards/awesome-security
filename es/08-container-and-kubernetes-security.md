# Seguridad de Contenedores, Docker y Kubernetes

> Defensa en tiempo de ejecución, auditoría de cumplimiento, escaneo de imágenes de contenedores y control de admisión para Kubernetes y Docker.

---

### [Falco](https://github.com/falcosecurity/falco) [![Stars](https://img.shields.io/github/stars/falcosecurity/falco?style=social)](https://github.com/falcosecurity/falco)
- Estándar de facto en seguridad de tiempo de ejecución cloud-native, que utiliza eBPF para detectar comportamientos anómalos e intrusiones en tiempo real.

### [kube-bench](https://github.com/aquasecurity/kube-bench) [![Stars](https://img.shields.io/github/stars/aquasecurity/kube-bench?style=social)](https://github.com/aquasecurity/kube-bench)
- Herramienta automatizada en Go que verifica si Kubernetes está implementado de forma segura ejecutando pruebas del CIS Kubernetes Benchmark.

### [kube-hunter](https://github.com/aquasecurity/kube-hunter) [![Stars](https://img.shields.io/github/stars/aquasecurity/kube-hunter?style=social)](https://github.com/aquasecurity/kube-hunter)
- Rastrea debilidades de seguridad y vulnerabilidades en clústeres de Kubernetes desde perspectivas internas y externas a la red.

### [Cosign (Sigstore)](https://github.com/sigstore/cosign) [![Stars](https://img.shields.io/github/stars/sigstore/cosign?style=social)](https://github.com/sigstore/cosign)
- Firma de contenedores, verificación y gestión de claves en registros OCI para cadenas de suministro de software verificables.

### [Hadolint](https://github.com/hadolint/hadolint) [![Stars](https://img.shields.io/github/stars/hadolint/hadolint?style=social)](https://github.com/hadolint/hadolint)
- Linter inteligente para Dockerfiles que aplica buenas prácticas y valida sintaxis con ShellCheck para evitar imágenes inseguras.
