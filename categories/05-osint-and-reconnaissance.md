# OSINT (Inteligencia de Fuentes Abiertas) y Reconocimiento Externo

> Techniques and utilities for collecting publicly accessible information, digital footprints, and mapping external attack surfaces.
> Técnicas e utilitários para coletar informações públicas, rastros digitais e mapear superfícies externas de ataque.
> Técnicas y utilidades para recopilar información pública, huellas digitales y mapear superficies de ataque externas.

---

### [Sherlock](https://github.com/sherlock-project/sherlock) [![Stars](https://img.shields.io/github/stars/sherlock-project/sherlock?style=social)](https://github.com/sherlock-project/sherlock)
* 🇺🇸 **EN:** Hunt down social media accounts by username across 400+ online platforms with high speed and zero false positives.
* 🇧🇷 **PT:** Rastreie contas em redes sociais por nome de usuário em mais de 400 plataformas online com alta velocidade.
* 🇪🇸 **ES:** Rastree cuentas en redes sociales por nombre de usuario en más de 400 plataformas en línea con alta velocidad.

### [theHarvester](https://github.com/laramies/theHarvester) [![Stars](https://img.shields.io/github/stars/laramies/theHarvester?style=social)](https://github.com/laramies/theHarvester)
* 🇺🇸 **EN:** Gathers emails, names, subdomains, IPs, and URLs using multiple public data sources and search engines during early assessment phases.
* 🇧🇷 **PT:** Coleta e-mails, nomes, subdomínios, IPs e URLs usando fontes públicas e mecanismos de busca durante fases iniciais de reconhecimento.
* 🇪🇸 **ES:** Recopila correos electrónicos, nombres, subdominios, IPs y URLs utilizando fuentes públicas y motores de búsqueda en fases de reconocimiento.

### [OWASP Amass](https://github.com/owasp-amass/amass) [![Stars](https://img.shields.io/github/stars/owasp-amass/amass?style=social)](https://github.com/owasp-amass/amass)
* 🇺🇸 **EN:** In-depth attack surface mapping and asset discovery framework employing open-source information gathering and active graph database techniques.
* 🇧🇷 **PT:** Framework aprofundado de mapeamento de superfície de ataque e descoberta de ativos utilizando coleta de dados e bancos em grafo.
* 🇪🇸 **ES:** Framework de mapeo de superficie de ataque y descubrimiento de activos mediante recopilación de fuentes abiertas y bases de datos en grafos.

### [Subfinder](https://github.com/projectdiscovery/subfinder) [![Stars](https://img.shields.io/github/stars/projectdiscovery/subfinder?style=social)](https://github.com/projectdiscovery/subfinder)
* 🇺🇸 **EN:** Fast passive subdomain enumeration tool designed to discover valid subdomains using passive online OSINT sources without touching targets.
* 🇧🇷 **PT:** Ferramenta rápida de enumeração passiva de subdomínios que descobre hosts válidos sem interagir diretamente com o alvo.
* 🇪🇸 **ES:** Herramienta rápida de enumeración pasiva de subdominios que descubre hosts válidos sin interactuar directamente con el objetivo.

### [SpiderFoot](https://github.com/smicallef/spiderfoot) [![Stars](https://img.shields.io/github/stars/smicallef/spiderfoot?style=social)](https://github.com/smicallef/spiderfoot)
* 🇺🇸 **EN:** Modular open-source intelligence automation tool integrating over 100 data modules to map target infrastructure and digital presence.
* 🇧🇷 **PT:** Ferramenta modular de automação de OSINT integrando mais de 100 módulos para mapear infraestrutura e presença digital de alvos.
* 🇪🇸 **ES:** Herramienta modular de automatización de OSINT que integra más de 100 módulos para mapear infraestructura y presencia digital de objetivos.

### [Recon-ng](https://github.com/lanmaster53/recon-ng) [![Stars](https://img.shields.io/github/stars/lanmaster53/recon-ng?style=social)](https://github.com/lanmaster53/recon-ng)
* 🇺🇸 **EN:** Full-featured command-line web reconnaissance framework with built-in database schema and independent modules mimicking Metasploit.
* 🇧🇷 **PT:** Framework completo de reconhecimento web via linha de comando com banco de dados integrado e arquitetura modular similar ao Metasploit.
* 🇪🇸 **ES:** Framework completo de reconocimiento web por línea de comandos con base de datos integrada y arquitectura modular similar a Metasploit.

### [Photon](https://github.com/s0md3v/Photon) [![Stars](https://img.shields.io/github/stars/s0md3v/Photon?style=social)](https://github.com/s0md3v/Photon)
* 🇺🇸 **EN:** Lightweight, lightning-fast web crawler built to extract URLs, parameters, JavaScript files, secret keys, and email addresses.
* 🇧🇷 **PT:** Crawler web extremamente leve e rápido criado para extrair URLs, parâmetros, arquivos JavaScript, chaves secretas e e-mails.
* 🇪🇸 **ES:** Rastreador web extremadamente ligero y rápido creado para extraer URLs, parámetros, archivos JavaScript, claves secretas y correos.
