# Detecção de Segredos e Vazamento de Credenciais
# Detección de Secretos y Fuga de Credenciales

> Analyzers that prevent and detect hardcoded secrets, API tokens, cryptographic private keys, and passwords across source code repositories and commit histories.
> Analisadores que previnem e detectam segredos hardcoded, tokens de API, chaves privadas e senhas em repositórios e históricos de commits.
> Analizadores que previenen y detectan secretos en código, tokens de API, claves privadas y contraseñas en repositorios e historiales de commits.

### [TruffleHog](https://github.com/trufflesecurity/trufflehog) [![Stars](https://img.shields.io/github/stars/trufflesecurity/trufflehog?style=social)](https://github.com/trufflesecurity/trufflehog)
* 🇺🇸 **EN:** High-performance secrets scanner searching Git commit history, filesystems, S3 buckets, and Docker images with live API verification.
* 🇧🇷 **PT:** Scanner de segredos de alto desempenho que vasculha o histórico do Git, sistemas de arquivos, S3 e Docker com verificação ativa em APIs.
* 🇪🇸 **ES:** Escáner de secretos de alto rendimiento que busca en el historial de Git, sistemas de archivos, S3 y Docker con verificación activa en APIs.

### [Gitleaks](https://github.com/gitleaks/gitleaks) [![Stars](https://img.shields.io/github/stars/gitleaks/gitleaks?style=social)](https://github.com/gitleaks/gitleaks)
* 🇺🇸 **EN:** Fast, lightweight, standalone tool and pre-commit hook designed to find hardcoded secrets in git repositories and CI/CD pipelines.
* 🇧🇷 **PT:** Ferramenta rápida, leve e independente com suporte a pre-commit hook para encontrar segredos hardcoded em repositórios e CI/CD.
* 🇪🇸 **ES:** Herramienta rápida y ligera con soporte para pre-commit hook para encontrar secretos en repositorios de Git y pipelines de CI/CD.

### [detect-secrets](https://github.com/Yelp/detect-secrets) [![Stars](https://img.shields.io/github/stars/Yelp/detect-secrets?style=social)](https://github.com/Yelp/detect-secrets)
* 🇺🇸 **EN:** Enterprise-grade secrets detection tool developed by Yelp utilizing heuristics and regular expressions with baseline tracking.
* 🇧🇷 **PT:** Ferramenta corporativa de detecção de segredos desenvolvida pela Yelp utilizando heurísticas e regex com rastreamento por baseline.
* 🇪🇸 **ES:** Herramienta empresarial de detección de secretos desarrollada por Yelp que utiliza heurísticas y expresiones regulares con seguimiento por baseline.
