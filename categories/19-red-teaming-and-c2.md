### [Metasploit Framework](https://github.com/rapid7/metasploit-framework) [![Stars](https://img.shields.io/github/stars/rapid7/metasploit-framework?style=social)](https://github.com/rapid7/metasploit-framework)
* 🇺🇸 **EN:** The world's most widely used penetration testing platform providing verified exploits, payload generation, and automation modules.
* 🇧🇷 **PT:** A plataforma de testes de invasão mais utilizada do mundo fornecendo exploits verificados, geração de payloads e automação.
* 🇪🇸 **ES:** La plataforma de pruebas de penetración más utilizada del mundo que proporciona exploits verificados, generación de cargas útiles y automatización.

### [Caldera (MITRE)](https://github.com/mitre/caldera) [![Stars](https://img.shields.io/github/stars/mitre/caldera?style=social)](https://github.com/mitre/caldera)
* 🇺🇸 **EN:** Cyber adversary emulation software platform built by MITRE directly mapped to the ATT&CK framework for automated red-team exercises.
* 🇧🇷 **PT:** Plataforma de software para emulação de adversários cibernéticos desenvolvida pelo MITRE mapeada diretamente na matriz ATT&CK.
* 🇪🇸 **ES:** Plataforma de emulación de adversarios cibernéticos desarrollada por MITRE mapeada directamente a la matriz ATT&CK.

### [Sliver](https://github.com/BishopFox/sliver) [![Stars](https://img.shields.io/github/stars/BishopFox/sliver?style=social)](https://github.com/BishopFox/sliver)
* 🇺🇸 **EN:** Open-source cross-platform adversary emulation and Command and Control (C2) framework developed by BishopFox in Go supporting mTLS, WireGuard, and DNS.
* 🇧🇷 **PT:** Framework open source e multiplataforma de Comando e Controle (C2) desenvolvido pela BishopFox em Go com suporte a mTLS e WireGuard.
* 🇪🇸 **ES:** Framework de código abierto y multiplataforma de Comando y Control (C2) desarrollado por BishopFox en Go con soporte para mTLS y WireGuard.

### [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) [![Stars](https://img.shields.io/github/stars/redcanaryco/atomic-red-team?style=social)](https://github.com/redcanaryco/atomic-red-team)
* 🇺🇸 **EN:** Library of simple, open-source, automated atomic tests mapped to the MITRE ATT&CK framework for validating defensive security controls.
* 🇧🇷 **PT:** Biblioteca de testes atômicos simples e automatizados mapeados para o MITRE ATT&CK para validar a eficácia de controles defensivos.
* 🇪🇸 **ES:** Biblioteca de pruebas atómicas simples y automatizadas mapeadas para MITRE ATT&CK para validar controles defensivos.

### [Mimikatz](https://github.com/gentilkiwi/mimikatz) [![Stars](https://img.shields.io/github/stars/gentilkiwi/mimikatz?style=social)](https://github.com/gentilkiwi/mimikatz)
* 🇺🇸 **EN:** Seminal tool that extracts plaintext passwords, hash digests, PIN codes, and kerberos tickets from memory on Windows systems (LSASS).
* 🇧🇷 **PT:** Ferramenta seminal que extrai senhas em texto puro, hashes, códigos PIN e tickets Kerberos da memória do Windows (LSASS).
* 🇪🇸 **ES:** Herramienta histórica que extrae contraseñas en texto plano, hashes, códigos PIN y tickets de Kerberos de la memoria de Windows (LSASS).
