# Cloud Security (CSPM, CIEM) & Infrastructure as Code (IaC)

> Auditing, compliance assessment, misconfiguration detection, and posture management across multi-cloud environments (AWS, GCP, Azure) and IaC templates.
> Auditoria, conformidade, detecção de erros de configuração e postura em ambientes multi-nuvem (AWS, GCP, Azure) e templates IaC.

---

### [Prowler](https://github.com/prowler-cloud/prowler) [![Stars](https://img.shields.io/github/stars/prowler-cloud/prowler?style=social)](https://github.com/prowler-cloud/prowler)
- Open-source security tool for AWS, Azure, GCP, and Kubernetes assessments, audits, incident response, and continuous compliance checks against CIS Benchmarks.

### [Checkov](https://github.com/bridgecrewio/checkov) [![Stars](https://img.shields.io/github/stars/bridgecrewio/checkov?style=social)](https://github.com/bridgecrewio/checkov)
- Static code analysis tool for Infrastructure as Code (IaC) scanning Terraform, CloudFormation, Kubernetes, Helm, ARM, and serverless configs.

### [ScoutSuite](https://github.com/nccgroup/ScoutSuite) [![Stars](https://img.shields.io/github/stars/nccgroup/ScoutSuite?style=social)](https://github.com/nccgroup/ScoutSuite)
- Multi-cloud security-auditing tool that gathers configuration data through cloud APIs to highlight risk areas in an intuitive HTML report.

### [KICS (Keeping Infrastructure as Code Secure)](https://github.com/Checkmarx/kics) [![Stars](https://img.shields.io/github/stars/Checkmarx/kics?style=social)](https://github.com/Checkmarx/kics)
- Open-source linter identifying vulnerabilities, compliance issues, and configuration defects across Terraform, Kubernetes, Ansible, and Dockerfile.

### [CloudFox](https://github.com/BishopFox/cloudfox) [![Stars](https://img.shields.io/github/stars/BishopFox/cloudfox?style=social)](https://github.com/BishopFox/cloudfox)
- Command-line tool designed to help penetration testers and security engineers discover exploitable attack paths in AWS and Azure environments.
